مزایا و معایب استفاده از بوت‌استرپ
============================================

استفاده از بوت‌استرپ می‌تواند ساخت صفحات وب را بسیار سرعت ببخشد
اما این ابزار، معایبی نیز دارد. در این بخش به مزایا و معایب این ابزار خواهیم پرداخت:

مزایای بوت‌استرپ
--------------------

- استفاده از بوت‌استرپ سرعت طراحی سایت را به کمک کلاس‌های آماده بسیار بالا می‌برد
- کامپوننت‌ها به شما کمک می‌کنند که وقت خودتان را برای بازطراحی عناصر پرکاربرد تلف نکنید
- کدهای آماده بوت‌استرپ توسط مهندسان و متخصصان کامپیوتر نوشته شده و اغلب از استانداردهای وب پیروی می‌کنند
- به دلیل پیروی از استانداردها، بوت‌استرپ در اکثر مرورگرها به درستی کار می‌کند
- کدهای بوت‌استرپ ریسپانسیو بوده و برای تمامی دستگاه‌ها از جمله موبایل، تبلت، و کامپیوتر بهینه شده‌اند



معایب بوت‌استرپ
------------------------

- سایت‌های ساخته شده با بوت‌ذاسترپ اکثراً ظاهری مشابه هم و تکراری دارند
- برای طراحی‌های خلاقانه، شما را محدود می‌کند
- برای سایت‌های کوچک که چند صفحه محدود دارند، استفاده از بوت‌استرپ حجم فایل‌های پروژه را بالا برده و سرعت بارگزاری سایت را کم می‌کند
