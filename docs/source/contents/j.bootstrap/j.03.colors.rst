رنگ‌ها در بوت‌استرپ
====================================

در فریم‌ورک بوت‌استرپ،
به صورت پیش‌فرض تعدادی رنگ تعریف شده است.
البته تعداد این رنگ‌ها محدود و کمتر از ده تاست.

رنگ‌ها در بوت‌استرپ به صورت **معناگرایانه** نام‌گذاری و انتخاب شده‌اند.
این رنگ‌ها عبارتند از:

* ``primary``: رنگ اصلی - آبی
* ``secondary``: رنگ ثانویه - خاکستری
* ``success``: موفقیت - سبز
* ``danger``: خطر - قرمز
* ``warning``: هشدار - زرد
* ``info``: اطلاعات و نکات - فیروزه‌ای
* ``dark``: تیره - مشکی
* ``light``: روشن - مایل به سفید

    رنگ‌ها در بوت‌استرپ

از رنگ‌ها می‌توان در پس‌زمینه عناصر،
متن‌ها،
دکمه‌ها،
کادرها
(border) و ...
استفاده کرد که هر کدام از این موارد کلاس مخصوص به خود را دارد.
به طور مثال برای تغییر رنگ متن به آبی از کلاس
``text-primary``
یا برای تغییر رنگ پس‌زمینه یک عنصر به سبز از کلاس
``bg-success``
استفاده می‌کنیم.

سفارشی‌سازی بوت‌استرپ
--------------------------

در صورتی که می‌خواهید رنگ‌ها و سایر تنظیمات بوت‌استرپ را
به دلخواه خود شخصی‌سازی کنید، باید کد منبع آن را دریافت
و متغیرهای مربوط به رنگ آن را ویرایش کنید.

.. admonition:: بیشتر بدانید
    :class: tip

    کدهای منبع بوت‌استرپ از یک پیش‌پردازنده CSS
    به نام SASS
    استفاده می‌کنند که نوشتن کدهای CSS
    را به کمک متغیرها،
    نوشتن تودرتوی انتخابگرها،
    و سایر امکانات،
    ساده‌تر می‌کند.
