ابزارهای تایپوگرافی در بوت‌استرپ
==========================================

تایپوگرافی (Typography) به نحوه‌ی نمایش متن در صفحه گفته می‌شود.
در طراحی وب، ظاهر حروف، اندازه‌ی آن‌ها، فاصله‌ها و نحوه‌ی چینش متون اهمیت زیادی دارد.
بوت‌استرپ مجموعه‌ای از کلاس‌های آماده در اختیار ما می‌گذارد تا بتوانیم بدون
نوشتن CSS جدید، متون را زیبا و خوانا نمایش دهیم.

در این نوشته، با ابزارهای پرکاربرد تایپوگرافی در بوت‌استرپ آشنا می‌شویم.


عناوین (Headings)
------------------

بوت‌استرپ از تگ‌های استاندارد HTML برای عنوان‌ها پشتیبانی می‌کند:
``<h1>`` تا ``<h6>``.
علاوه بر آن، کلاس‌هایی برای ساخت عنوان‌هایی با اندازه‌ی مشابه وجود دارد.

**نمونه‌ها:**

.. code-block:: html

    <h1>عنوان سطح ۱</h1>
    <h2>عنوان سطح ۲</h2>
    <h3>عنوان سطح ۳</h3>

یا با استفاده از کلاس‌ها:

.. code-block:: html

    <p class="h1">عنوان بزرگ با تگ پاراگراف</p>
    <p class="h4">عنوان متوسط</p>

این کار زمانی مفید است که بخواهیم ظاهری مانند عنوان داشته باشیم
اما از نظر معنایی تگ دیگری (مثل ``<p>``) استفاده کنیم.


متن معمولی (Body Text)
-----------------------

بوت‌استرپ برای تنظیم ظاهر پاراگراف‌ها به‌صورت پیش‌فرض اندازه‌ی مناسب،
ارتفاع خط (line-height) و فاصله‌ی درست میان خطوط را تنظیم کرده است.

همچنین با استفاده از کلاس ``lead`` می‌توان پاراگرافی را کمی بزرگ‌تر و برجسته‌تر نمایش داد.

.. code-block:: html

    <p>این یک متن معمولی است.</p>
    <p class="lead">این پاراگراف تأکید بیشتری دارد.</p>

وزن و شکل قلم (Font Weight & Style)
-----------------------------------

برای تغییر وزن (ضخامت) یا حالت حروف می‌توان از کلاس‌های زیر استفاده کرد:

- ``fw-bold`` : متن پررنگ
- ``fw-semibold`` : متن نیمه‌پررنگ
- ``fw-normal`` : حالت عادی
- ``fw-light`` : حالت ظریف
- ``fst-italic`` : حالت ایتالیک (مایل)

**نمونه:**

.. code-block:: html

    <p class="fw-bold">این متن پررنگ است.</p>
    <p class="fst-italic">این متن مایل است.</p>

تراز متن (Text Alignment)
--------------------------

متن‌ها را می‌توان به‌سادگی در راست، چپ یا وسط صفحه قرار داد.

کلاس‌های اصلی:

- ``text-start`` : تراز از سمت شروع (در زبان فارسی، راست و در زبان انگلیسی، چپ)
- ``text-center`` : تراز وسط
- ``text-end`` : تراز از سمت پایان (در زبان فارسی، چپ و در زبان انگلیسی، راست)

.. code-block:: html

    <p class="text-start">این متن راست‌چین است.</p>
    <p class="text-center">این متن وسط‌چین است.</p>
    <p class="text-end">این متن چپ‌چین است.</p>

رنگ متن (Text Color)
------------------------

برای رنگ‌دهی به متن‌ها، بوت‌استرپ کلاس‌های رنگی از پیش‌تعریف‌شده دارد.
این رنگ‌ها، همان رنگ‌های معناگرایانه‌ای هستند که در فصل پیش به آن‌ها اشاره شد:

- ``text-primary`` : رنگ اصلی (معمولاً آبی)
- ``text-success`` : نشانه‌ی موفقیت (سبز)
- ``text-danger`` : نشانه‌ی هشدار یا خطا (قرمز)
- ``text-warning`` : رنگ هشدار (زرد یا نارنجی)
- ``text-info`` : اطلاع‌رسانی (آبی روشن)
- ``text-muted`` : متن کم‌رنگ‌تر

**مثال:**

  رنگ متن‌ها در بوت‌استرپ

.. code-block:: html

    <p class="text-primary">این یک متن با رنگ اصلی است.</p>
    <p class="text-success">این متن موفقیت‌آمیز است.</p>
    <p class="text-muted">این متن کم‌رنگ‌تر است.</p>

تبدیل حروف (Text Transformation)
---------------------------------

با چند کلاس ساده می‌توان حالت نوشتاری متن را تغییر داد:

- ``text-uppercase`` : تمام حروف را تبدیل به حروف بزرگ می‌کند
- ``text-lowercase`` : تمام حروف را تبدیل به حروف کوچک می‌کند
- ``text-capitalize`` : اولین حرف هر واژه را بزرگ می‌کند

اندازه‌ی متن (Font Size)
-------------------------

اندازه‌ی متن‌ها را می‌توان با کلاس‌های آماده از ``fs-1`` تا ``fs-6`` تغییر داد.

``fs-1`` بزرگ‌ترین و ``fs-6`` کوچک‌ترین متن است.

.. code-block:: html

    <p class="fs-1">متن بسیار بزرگ</p>
    <p class="fs-3">متن متوسط</p>
    <p class="fs-6">متن کوچک</p>
