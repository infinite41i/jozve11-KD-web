=====================================================

بوت استرپ
(Bootstrap)
یک فریم ورک
CSS
رایگان و متن باز است که برای توسعه صفحات وب واکنش‌گرا
(Responsive)
ایجاد شده است و به ما کمک می‌کند صحفات وب را با سرعت بسیار بالاتری آماده کنیم.

این ابزار به کمک کلاس‌های آماده
CSS
و کدهای آماده
Javascript
کار می‌کند. یعنی به جای این که برای هر عنصر یک کلاس بسازیم و به آن ویژگی‌های
CSS
بدهیم، برعکس عمل می‌کنیم؛
یعنی یک سری کلاس از قبل ساخته شده و ما از آن‌ها استفاده می‌کنیم.

   این فریم‌ورک علاوه بر ریسپانسیو بودن Mobile-First نیز هست.

   Mobile-First می‌توان ابتدا وب سایت را برای صفحه نمایش‌های کوچک تلفن همراه آماده کرد
   و به مرور زمان وب سایت را برای صفحه نمایش‌های بزرگ‌تر نیز توسعه داد.
