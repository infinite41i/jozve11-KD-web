نصب و راه‌اندازی بوت‌استرپ
=====================================================

به دو شیوه می‌توان از بوت‌استرپ استفاده کرد:

۱- نصب محلی در پروژه
-----------------------------

بدین منظور ابتدا از 
`سایت رسمی بوت‌استرپ <https://getbootstrap.com/>`_ 
نسخه مناسب را دانلود کنید. جدیدترین نسخه بوت‌استرپ تا الان نسخه ۵ است
اما نسخه ۴ هم همچنان بسیار استفاده می‌شود.

همچنین شما می‌توانید فایل نسخه ۵ بوت‌استرپ را از 
`اینجا <https://jozve11kd.s3.ir-thr-at1.arvanstorage.ir/bootstrap-5.3.3-dist.zip?versionId=>`_
دانلود کنید.

درون این فایل دو پوشه به نام‌های
CSS
و
JS
قرار دارد.
از پوشه
CSS
فایل
``bootstrap.min.css``
و از پوشه
JS
فایل 
``bootstrap.bundle.min.js``
را در مسیر پروژه کپی کنید.

سپس در صفحه وب خود،
به این فایل‌ها به این صورت لینک می‌دهیم.
کافیست قطعه کد زیر را به عنصر
head
صفحه وب اضافه کنید.

.. code-block:: html

     <link rel="stylesheet" href="./css/bootstrap.min.css">
     <script src="./js/bootstrap.bundle.min.js"></script>


۲- استفاده از CDN
-----------------------

**CDN**
یا
**شبکه توزیع محتوا**
در واقع یک سرور پر سرعت است که
فایل‌های پرکاربرد که مورد استفاده اکثر سایت‌ها است را
ذخیره سازی کرده و هر سایتی می‌تواند به جای آپلود کردن
فایل‌های فریم‌ورک‌های پرکاربردی مثل
Bootstrap
و
JQuery
و ...
در سرور خودش، به این سرور پرسرعت لینک بدهد
و فایل ها را از اینجا در صفحات وب بارگزاری کند.

مزیت استفاده از CDN
^^^^^^^^^^^^^^^^^^^^^^^^^^^

سرورهای
CDN
سرعت خیلی بالایی در بارگزاری فایل‌ها دارند و از
آنجایی که این فایل‌ها در بسیار در صفحات وب پرکاربرد هستند،
در نزدیک ترین سرور کَش
(cache)
می‌شوند.
در نتیجه صفحه سریع تر بارگزاری می‌شود.

معایب استفاده از CDN
^^^^^^^^^^^^^^^^^^^^^^^^^^^

اما این روش معایبی نیز دارد.
مثلا این که اگر سرور های
CDN
دچار مشکل شوند،
سایت شما نیز به درستی بارگذاری نخواهد شد.
هرچند معمولا این اتفاق نمی‌افتد و
این سرور ها آپتایم
(uptime)
و پایداری بالایی دارند،
اما در شرایط خاص مثل قطع اینترنت بین‌المللی
سایت شما با مشکل روبرو خواهد شد.

بنابراین اگر سرور سایت شما در ایران قرار دارد بهتر است
که از
CDN
های ایرانی مثل آروان‌کلاود و پارس پک استفاده کنید.
یا اگر این روش نیز مقدور نبود می‌توانید از روش اول کمک بگیرید.
