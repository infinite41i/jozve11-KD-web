ترکیب انتخابگرها در CSS
========================

در CSS برای هدف‌گیری دقیق‌تر عناصر، می‌توان از **ترکیب‌کننده‌ها (Combinators)** بین انتخابگرها استفاده کرد. این ترکیب‌کننده‌ها مشخص می‌کنند رابطه و موقعیت عناصر در HTML چگونه باشد.

انواع ترکیب‌کننده‌ها
--------------------

ترکیبگر ساده (علامت ``,``)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

همه‌ی عناصر انتخاب شده را همزمان قالب‌دهی می‌کند.

.. admonition:: مثال

    .. code-block:: css

        h1, h2, h3, h4, h5, h6 { color: red; }

    تمام عنوان‌ها از هر سطحی که باشند قرمز می‌شوند.


Descendant Combinator (فاصله یا Space) - انتخابگر نواده (فرزند مستقیم و غیرمستقیم)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

عنصری که فرزند عنصر اول باشد را انتخاب می‌کند؛ چه مستقیم باشد چه غیرمستقیم.

.. admonition:: مثال

    .. code-block:: css

        div p { color: red; }

    تمام ``<p>``هایی که درون ``<div>`` قرار دارند (چه مستقیم چه غیرمستقیم) قرمز می‌شوند.

Child Combinator (علامت ``>``) - انتخابگر فرزند (مستقیم)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

عنصری که مستقیما و فقط با یک سطح فاصله فرزند عنصر اول باشد را انتخاب می‌کند.

.. admonition:: مثال

    .. code-block:: css

        div > p { color: blue; }

    تنها ``<p>``هایی که مستقیماً درون ``<div>`` هستند آبی می‌شوند، نه آن‌هایی که در سطوح پایین‌تر قرار دارند.

Next Sibling Combinator (علامت +) - اتخابگر هم‌والد مجاور
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

انتخاب عنصری که *بلافاصله بعد از* عنصر مشخص‌شده قرار دارد.  

.. admonition:: مثال

    .. code-block:: css

        h2 + p { margin-top: 0; }

    فقط اولین ``<p>``ی که درست بعد از یک ``<h2>`` می‌آید تحت تأثیر قرار می‌گیرد.

Subsequent-Sibling Combinator (علامت ``~``) - انتخابگر هم‌والد رو به جلو
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

انتخاب تمام عناصری که در همان سطح هستند (هم‌والد هستند) و *بعد از* عنصر انتخاب‌شده می‌آیند.  

.. admonition:: مثال

    .. code-block:: css

        h2 ~ p { color: gray; }

    تمام ``<p>`` هایی که در همان سطح و بعد از ``<h2>`` قرار دارند خاکستری می‌شوند.
