ویژگی‌های پرکاربرد در CSS
===============================

ویژگی‌ها (Properties) در CSS مشخص می‌کنند که هر عنصر دقیقاً چگونه باید نمایش داده شود — از رنگ و اندازه گرفته تا موقعیت و شیوه تعامل با کاربر. در اینجا چند ویژگی بسیار رایج و بنیادین را معرفی می‌کنیم که در اکثر پروژه‌های طراحی وب استفاده می‌شوند.

۱. ویژگی color
----------------------

این ویژگی رنگ متن را برای یک عنصر مشخص می‌کند. مقدار آن می‌تواند با استفاده از نام رنگ (مانند `red`)، کد هگزادسیمال (`#ff0000`)، مقدار RGB، یا حتی متغیرهای CSS تعیین شود.

مثال:  

.. code-block:: css

    p { color: #333; }

این قطعه کد باعث می‌شود تمام پاراگراف‌ها با رنگ خاکستری تیره نمایش داده می‌شوند.

۲. ویژگی background-color
------------------------------

این ویژگی رنگ پس‌زمینه عنصر را مشخص می‌کند.

مثال:  

.. code-block:: css

    div { background-color: lightblue; }

در خروجی تمام عناصر `div` با پس‌زمینه آبی روشن نمایش داده می‌شوند.

۳. ویژگی font-size
---------------------

*   اندازه فونت متن داخل عنصر را تعیین می‌کند. اندازه می‌تواند بر حسب پیکسل (`px`)، درصد (`%`)، یا واحدهای نسبی (`em`, `rem`) اعلام شود.
*   نکته: برای طراحی واکنش‌گرا بهتر است از واحدهای نسبی (`rem`) استفاده شود تا نسبت به اندازه پایه سند تنظیم شود.
*   مثال:  
    ``h2 { font-size: 1.8rem; }``  
    — اندازه تیترهای سطح دوم به ۱٫۸ برابر اندازه متن پایه تغییر می‌کند.

۴. ویژگی border
-------------------

*   برای نمایش یک خط حاشیه دور عنصر استفاده می‌شود. می‌توان ضخامت، نوع، و رنگ مرز را تنظیم کرد.
*   کاربرد: مرزها اغلب برای جداسازی عناصر یا تمرکز توجه کاربر روی بخش خاصی از طراحی به کار می‌روند.
*   مثال:  
    ``img { border: 2px solid #444; }``  
    — تصاویر با مرز خاکستری تیره و ضخامت ۲ پیکسل نمایش داده می‌شوند.

۵. ویژگی width و height
---------------------------

*   عرض (`width`) و ارتفاع (`height`) عنصر را مشخص می‌کنند و در کنار `box-sizing` رفتار جعبه را کنترل می‌نمایند.
*   مثال:  
    ``.card { width: 300px; height: 200px; }``  
    — کارت‌ها با اندازه دقیق ۳۰۰×۲۰۰ پیکسل نمایش داده می‌شوند.

۶. ویژگی text-align
-------------------------

*   نحوه چیدمان متن داخل عنصر را مشخص می‌کند. مقدارهایی مانند `left`, `right`, `center`, و `justify` برای کنترل تراز استفاده می‌شوند.
*   مثال:  
    ``h1 { text-align: center; }``  
    — تیتر اصلی در وسط صفحه قرار می‌گیرد.
