CSS چیست؟
===============

وقتی صفحه‌ای با HTML درست می‌کنیم، فقط **ساختار محتوا** را مشخص کرده‌ایم؛ مثل عنوان، پاراگراف، لیست یا جدول.  
اما اگر بخواهیم صفحه‌مان زیباتر شود — مثل تعیین رنگ‌ها، فونت‌ها، حاشیه‌ها و پس‌زمینه - باید از CSS استفاده کنیم.

۱. CSS چیست و چه کار می‌کند؟
--------------------------------------

CSS مخفف "Cascading Style Sheets" به معنی «برگه‌های قالب‌دهی آبشاری» است.
CSS به مرورگر می‌گوید که هر قسمت از صفحه (مثل تیترها، پاراگراف‌ها، دکمه‌ها) *چگونه* دیده شود.
CSS مسئول تمام جنبه‌های ظاهری است: رنگ‌ها، اندازه‌ها، فونت‌ها، فاصله‌ها، و محل قرارگیری عناصر در صفحه.

..     :class: hint

..     کلمه «آبشاری»

..     *   قانون آبشار: اگر شما به یک متن بگویید "قرمز باش" و بعداً بگویید "آبی باش"، CSS بر اساس یک سلسله مراتب، تصمیم می‌گیرد که کدام دستور آخر (یا مهم‌تر) اعمال شود. این تضمین می‌کند که استایل نهایی صفحه همیشه قابل پیش‌بینی باشد.
