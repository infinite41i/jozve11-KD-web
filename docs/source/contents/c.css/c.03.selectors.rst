انتخابگرهای ساده CSS
=============================

انتخابگرها (Selectors)
در CSS
دقیقاً مشخص می‌کنند که چه عنصری در صفحه‌ی HTML
باید استایل‌دهی شود.
سه نوع انتخابگر پایه‌ای که هر توسعه‌دهنده‌ای باید بداند عبارتند از:
انتخابگر عمومی،
انتخابگر شناسه (ID)،
و انتخابگر کلاس (Class).
درباره‌ی سایر انتخابگرها در ادامه توضیح خواهیم داد.

۱. انتخابگر عمومی (Universal Selector)
----------------------------------------------

این انتخابگر با استفاده از علامت ستاره (*) نمایش داده می‌شود و هدف آن اعمال یک استایل یکسان بر روی **تمام** عناصر موجود در سند HTML است.

*   این انتخابگر جهانی یا عمومی است و به مرورگر فرمان می‌دهد که هر تگ یا عنصری را که در سند پیدا می‌کند، با استایل تعریف‌شده در این بخش مطابقت دهد.
*   کاربرد: معمولاً برای تنظیمات پیش‌فرض سراسری مانند حذف فاصله حاشیه‌ای (Margin) یا فاصله‌ی داخلی (Padding) از تمام عناصر به کار گرفته می‌شود.

۲. انتخابگر عنصر (Element Selector)
----------------------------------------------

انتخابگر عنصر، که گاهی اوقات انتخابگر نوع (Type Selector) نیز نامیده می‌شود، به سادگی با استفاده از نام تگ HTML مورد نظر (مانند `p`, `h1`, `div`، یا `a`) تعریف می‌شود و تمام نمونه‌های آن تگ را در صفحه هدف قرار می‌دهد.

*   این انتخابگر پایه و اساس استایل‌دهی در CSS محسوب می‌شود و هر استایلی که برای آن تعریف گردد، به طور پیش‌فرض بر روی تمامی نمونه‌های آن تگ در کل سند اعمال می‌گردد مگر اینکه یک انتخابگر با اولویت بالاتر آن را بازنویسی کند.
*   اولویت و قدرت: این انتخابگر ضعیف‌ترین سطح اولویت را در بین تمام انتخابگرهای بالا دارد، زیرا انتخابی بسیار عمومی است و انتخابگرهای ID، کلاس یا استایل‌های درون خطی (Inline Styles) اولویت بالاتری نسبت به آن دارند و اگر قالب‌بندی‌ای در آنها تعریف شود، آن قالب بندی به عنصر اعمال خواهد شد.
*   مثال: برای تنظیم رنگ تمام پاراگراف‌های یک وب‌سایت به رنگ خاکستری تیره، کد ``p { color: #555; }`` نوشته می‌شود که تمام تگ‌های `<p>` را هدف قرار می‌دهد.

۳. انتخابگر شناسه (ID Selector)
--------------------------------------

انتخابگر شناسه با علامت هش (`#`) آغاز می‌شود و برای استایل‌دهی به یک عنصر **منحصر به فرد** در کل صفحه استفاده می‌گردد.
ما می‌توانیم به هر عنصر یک شناسه منحصر به فرد بدهیم تا بتوانیم آن را شناسایی کرده و در فایل css
یا در لینک دهی بتوانیم به آن عنصر اشاره کنیم.

.. tip::

    این کار مانند این است که دانش‌آموزان یک کلاس را به کمک کد ملی‌شان از یکدیگر متمایز کنیم.

در تگ های HTML
شناسه را با ویژگی id تعیین می‌کنیم.
مثال:

.. code-block:: html

    <p id="paragraph1">متن پاراگراف</p>

اولویت و قدرت: این انتخابگر دارای بالاترین سطح اولویت در بین انتخابگرهای ساده است و اگر بین کلاس و شناسه تداخلی پیش آید، استایل تعریف‌شده برای شناسه همواره پیروز خواهد شد.

مثال: برای استایل‌دهی به یک نوار ناوبری اصلی که تنها یک نمونه در صفحه دارد، از کد ``#main-nav { background-color: #333; }`` استفاده می‌شود که به تگ ``<nav id="main-nav">`` اعمال خواهد شد.

.. attention:: 
    شناسه (ID) باید یک نام یکتا برای یک عنصر خاص در سند HTML باشد و نباید در یک صفحه بیش از یک بار از یک ID استفاده شود.

۴. انتخابگر کلاس (Class Selector)
----------------------------------------

انتخابگر کلاس با نقطه (`.`) آغاز می‌شود و برای اعمال استایل به **گروهی** از عناصر که ویژگی‌های ظاهری مشترکی دارند، به کار می‌رود.

.. note:: 

    برخلاف شناسه، یک کلاس می‌تواند به تعداد نامحدودی از عناصر در یک صفحه اختصاص یابد و همچنین یک عنصر می‌تواند همزمان چندین کلاس مختلف داشته باشد.

در تگ های HTML
شناسه را با ویژگی class تعیین می‌کنیم.
مثال:

.. code-block:: html

    <p class="red-text">متن پاراگراف</p>

ما می‌توانیم به طور همزمان چندین کلاس به یک عنصر بدهیم.
برای این کار کافیست کلاس‌ها را به کمک فاصله (space)
از یکدیگر جدا کنیم.
مثال:

.. code-block:: html

    <p class="red-text blue-border">متن پاراگراف</p>

*   انعطاف‌پذیری: این انتخابگر انعطاف‌پذیری بسیار بالایی را فراهم می‌کند زیرا می‌توان ترکیبی از استایل‌های مختلف را بر اساس نیاز لحظه‌ای به یک عنصر اختصاص داد.
*   مثال: برای برجسته‌سازی یک قسمت مهم در متن، می‌توان از کد ``.important-text { color: red; font-weight: bold; }`` استفاده کرد و آن را به چندین پاراگراف با تگ ``<p class="important-text">`` اعمال نمود.
