روش‌های استایل‌دهی به عناصر HTML
========================================

1.  **استفاده از ویژگی** `style` **در تگ‌های HTML (روش درون‌خطی)**
2.  **استفاده از تگ** `<style>` **در بخش** `<head>` **سند (روش داخلی)**
3.  **استفاده از فایل جداگانه‌ی CSS و پیوند دادن آن با تگ** `<link>` **(روش خارجی)**

در ادامه هر روش را با مثال توضیح می‌دهیم.

روش اول: ویژگی درون‌خطی style
-----------------------------------

در این روش، استایل (قالب) را **مستقیماً داخل تگ HTML** می‌نویسیم.  
این ساده‌ترین ولی ابتدایی‌ترین روش است.

.. code-block:: html

   <p style="color: blue; font-size: 18px;">
       این یک پاراگراف آبی است.
   </p>

هر ویژگی درون `style` با **نام ویژگی CSS** نوشته می‌شود (مثل `color` یا `font-size`) و بین آن‌ها از `;` استفاده می‌شود.


**ویژگی‌ها:**

* این روش برای تغییر یک بخش خاص، ساده‌ترین و سریع‌ترین راه ممکن به شمار می‌رود.  
* با این حال اگر بخواهیم ظاهر چند عنصر مشابه را تغییر دهیم، باید هر بخش را جداگانه ویرایش کنیم که این کار زمان‌بر و غیربهینه است.

روش دوم: تگ style در بخش head
--------------------------------------

در این روش، قوانین CSS را داخل **تگ `<style>`** در قسمت `<head>` صفحه می‌نویسیم.  
در این حالت، می‌توانیم با تعیین **انتخابگر (Selector)**، برای چندین عنصر همزمان قالب بدهیم.

.. code-block:: html

   <html>
   <head>
       <style>
           p {
               color: green;
               font-size: 20px;
           }

           h1 {
               text-align: center;
           }
       </style>
   </head>
   <body>
       <h1>عنوان صفحه</h1>
       <p>این یک پاراگراف سبز است.</p>
   </body>
   </html>

**ویژگی‌ها:**

* در این روش، قواعد CSS از محتوای اصلی صفحه جدا می‌شوند و در ابتدای سند در دسترس قرار می‌گیرند، در نتیجه ساختار کد خواناتر می‌شود.  
* وقتی تغییری در یک قانون CSS ایجاد شود، آن تغییر به طور خودکار بر روی تمام عناصر مشابه در همان صفحه اعمال می‌شود.  
* این روش برای صفحاتی که اندازه‌ی متوسطی دارند و نیاز به هماهنگی داخلی بین چند عنصر دارند، بسیار مناسب است.


روش سوم: فایل CSS جداگانه (خارجی)
-----------------------------------------

بهترین و حرفه‌ای‌ترین روش استفاده از **فایل CSS جداگانه** است.  
قواعد را در فایلی مثلاً `style.css` می‌نویسیم و سپس با تگ `<link>` به HTML متصل می‌کنیم.

.. code-block:: html

   <!-- در فایل HTML -->
   <head>
       <link rel="stylesheet" href="style.css">
   </head>

   <body>
       <h1>عنوان سایت</h1>
       <p>این متن از فایل CSS قالب گرفته است.</p>
   </body>

.. code-block:: css

   /* در فایل style.css */
   body {
       background-color: #f5f5f5;
   }

   p {
       color: darkblue;
       font-size: 18px;
   }

**ویژگی‌ها:**

* در این روش تمام قوانین مربوط به ظاهر سایت در یک فایل مجزا ذخیره می‌شوند و فایل
  HTML فقط به آن متصل می‌شود.
  این کار باعث می‌شود محتوا از قالب بندی جدا شود و هیچ کد مربوط به قالب بندی در فایل HTML
  نباشد و تمامی قالب بندی در CSS
  انجام شود.
* می‌توانیم یک فایل CSS
  را در چندین صفحه HTML
  که قالب یکسانی دارند استفاده کنیم.
  این کار باعث جلوگیری از نوشتن کد تکراری و کاهش حجم فایل‌های پروژه می‌شود.
* استفاده از فایل جداگانه باعث افزایش سرعت بارگذاری صفحات HTML می‌شود.
* این روش برای پروژه‌های بزرگ، چندصفحه‌ای و تیمی بهترین و حرفه‌ای‌ترین گزینه محسوب می‌شود.  


چرا روش دوم و سوم بهترند؟
----------------------------------

وقتی از CSS **درون‌خطی** استفاده می‌کنیم، ظاهر و محتوا در هم آمیخته می‌شوند.  
این کار باعث می‌شود:

* فایل HTML شلوغ و غیرقابل نگهداری شود.  
* ویرایش کدها دشوار شود.  

اما وقتی از روش دوم (تگ `<style>`)
یا سوم (فایل جداگانه‌ی CSS)
استفاده می‌کنیم:

* **ظاهر و محتوا از هم جدا می‌شوند.**  
* می‌توانیم از یک استایل تکراری در چند صفحه استفاده کنیم.  
* صفحه سریع‌تر و منظم‌تر خواهد بود.

.. note::
    در واقع، کنسرسیوم جهانی وب (W3C) — که استانداردهای HTML و CSS را تعریف می‌کند — توصیه می‌کند که:

    **«بهتر است محتوای HTML از قالب‌بندی CSS جدا باشد.»**

    این یعنی:
    HTML برای **معنا و ساختار** است،  
    CSS برای **ظاهر و زیبایی**.

این جداسازی اصل مهمی است که باعث می‌شود صفحات تر و تمیز، سریع و قابل نگهداری ساخته شوند.
