عناصر قالب‌بندی محتوایی متن در HTML
=========================================

HTML شامل عناصر مختلفی برای تعریف متن با معنای خاص است.

عنصر <strong>
--------------------

برای برجسته (bold)
کردن متن به کار می‌رود.
این برجسته کردن صرفاً ظاهری نیست بلکه معنای اهمیت و تاکید نیز دارد.
بدین ترتیب این برچسب باعث می‌شود که علاوه بر برجسته نشان داده شدن متن،
نرم‌افزار های صفحه‌خوان که برای افراد نابینا محتویات صفحه را به تبدیل به صوت می‌کنند،
آن قسمت از متن را با لحن تاکیدی می‌خواند.
همچنین موتورهای جستجو و ربات‌هایی که صفحات وب را بررسی می‌کنند نیز متوجه اهمیت قسمت
مشخص شده با برچسب <strong>
می‌شوند.

.. admonition:: مثال

    .. code-block:: html

        <p>این یک پاراگراف متن است.
            <strong>این قسمت از متن خیلی مهم است!</strong>
        </p>

    خروجی:

    .. raw:: html

        <p>این یک پاراگراف متن است. <strong>این قسمت از متن خیلی مهم است!</strong></p>


عنصر <em>
-------------

برای
**تاکید**
و تعیین کلمه محوری جمله استفاده می‌شود.
متن نوشته شده در این برچسب از لحاظ ظاهری مشابه متن italic
یا کج در نرم‌افزار ورد خواهد شد.
این تگ نیز از لحاظ معنایی اهمیت دارد و صرفا برای تغییر ظاهر متن نیست.

.. admonition:: مثال

    .. code-block:: html

        <p>این یک پاراگراف متن است.
            <em>این قسمت از متن به صورت کج نمایش داده می‌شود!</em>
        </p>

    خروجی:

    .. raw:: html

        <p>این یک پاراگراف متن است. <em>این قسمت از متن به صورت کج نمایش داده می‌شود!</em></p>


عنصر <mark>
-------------
    
برای مشخص کردن متنی که به نحوی
**هایلایت**
یا برجسته شده است
(مانند هایلایتر زرد روی یک پاراگراف).

.. admonition:: مثال

    .. code-block:: html

        <p>این یک پاراگراف متن است.
            <mark>این قسمت از متن هایلایت شده است!</mark>
        </p>

    خروجی:

    .. raw:: html

        <p>این یک پاراگراف متن است.
            <mark>این قسمت از متن هایلایت شده است!</mark>
        </p>

عنصر <del>
-------------

متنی را که از سند
**حذف شده**
با کشیدن یک خط روی متن نمایش می‌دهد.

.. admonition:: مثال

    .. code-block:: html

        <p>این یک پاراگراف متن است.
            <del>این قسمت از متن حذف شده است!</del>
        </p>

    خروجی:

    .. raw:: html

        <p>این یک پاراگراف متن است.
            <del>این قسمت از متن حذف شده است!</del>
        </p>

عنصر <ins>
-------------

متنی را که به سند
**اضافه شده**
به کمک کشیدن یک خط زیر آن نمایش می‌دهد (معمولاً در کنار ``<del>`` به کار می‌رود).

.. admonition:: مثال

    .. code-block:: html

        <p>این یک پاراگراف متن است.
            <ins>این قسمت از متن اضافه شده است!</ins>
        </p>

    خروجی:

    .. raw:: html

        <p>این یک پاراگراف متن است.
            <ins>این قسمت از متن اضافه شده است!</ins>
        </p>

عنصر <small>
-----------------
متن را کمی **کوچک‌تر** از متن اصلی نمایش می‌دهد (مانند پاورقی یا توضیحات حقوقی کوچک).

.. admonition:: مثال

    .. code-block:: html

        <p>این یک پاراگراف متن است.
            <small>این قسمت از متن کوچک‌تر نمایش داده می‌شود!</small>
        </p>

    خروجی:

    .. raw:: html

        <p>این یک پاراگراف متن است.
            <small>این قسمت از متن کوچک‌تر نمایش داده می‌شود!</small>
        </p>

عنصر <sub> (زیرنویس - Subscript)
------------------------------------
متن را به صورت **زیروند یا اندیس** (پایین خط اصلی) نمایش می‌دهد. کاربرد اصلی در فرمول‌های شیمیایی (مثلاً H\ :sub:`2`\ O).

.. admonition:: مثال

    .. code-block:: html

        <p>فرمول شیمیایی آب:
            H<sub>2</sub>O
        </p>

    خروجی:

    .. raw:: html

        <p>فرمول شیمیایی آب: H<sub>2</sub>O</p>

عنصر <sup> (بالانویس - Superscript)
-------------------------------------

متن را به 
**بالانویس**
(بالای خط اصلی) نمایش می‌دهد. کاربرد اصلی در توان ریاضی
(مثلاً x\ :sup:`2`)
یا ارجاعات (مثلاً پاورقی ۱).

.. admonition:: مثال

    .. code-block:: html

        <p>مربع عدد x برابر است با x<sup>2</sup></p>

    خروجی:

    .. raw:: html

        <p>مربع عدد x برابر است با
            x<sup>2</sup>
        </p>
