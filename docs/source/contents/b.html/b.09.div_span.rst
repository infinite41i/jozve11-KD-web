عناصر div و span
=====================

این دو عنصر از مهم‌ترین عناصر ساختاری در HTML هستند که برای گروه‌بندی و سازماندهی محتوا به کار می‌روند.

عنصر div
-----------

عنصر `div`
یک عنصر بلوکی (block-level)
است که معمولاً برای تقسیم
صفحه به بخش‌های مختلف استفاده می‌شود.
این عنصر به شما امکان می‌دهد تا بخش‌های مختلفی از محتوا را که ممکن است شامل متن، تصاویر، یا سایر عناصر HTML
باشد،
در یک بلوک جداگانه قرار دهید.

.. code-block:: html

    <div>
        <h1>عنوان اصلی</h1>
        <p>متن فرضی</p>
        <img src="image.jpg" alt="تصویر نمونه">
    </div>

.. note:: 

    یکی از مهم‌ترین کاربردهای div گروه‌بندی عناصر و قالب‌دهی آن گروه به کمک CSS است.


عنصر span
-------------

این عنصر یک عنصر درون خطی (inline)
است که برای گروه‌بندی بخش‌های کوچکتر از متن یا سایر عناصر درون یک خط استفاده می‌شود.

.. code-block:: html

    <p>
        یک متن
        <span style="color: red;">با رنگ قرمز</span>
        درون یک پاراگراف.
    </p>

خروجی:

.. raw:: html

    <p>یک متن <span style="color: red;">با رنگ قرمز</span> درون یک پاراگراف.</p>
