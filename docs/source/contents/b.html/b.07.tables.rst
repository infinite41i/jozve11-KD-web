جدول‌ها در HTML
====================

گاهی لازم داریم اطلاعات را به صورت منظم و در قالب سطر (ردیف) و ستون نمایش دهیم.
برای این کار از *جدول‌ها (Tables)* در HTML استفاده می‌کنیم.

هر جدول در HTML با تگ ``<table>`` ساخته می‌شود.
درون جدول، سطرهای آن با تگ ``<tr>`` (مخفف Table Row) مشخص می‌شوند
و هر خانه از جدول با تگ ``<td>`` (مخفف Table Data) نمایش داده می‌شود.

ساختار کلی یک جدول:
-------------------------

.. code-block:: html

   <table>
       <tr>
           <td>سطر ۱، ستون ۱</td>
           <td>سطر ۱، ستون ۲</td>
       </tr>
       <tr>
           <td>سطر ۲، ستون ۱</td>
           <td>سطر ۲، ستون ۲</td>
       </tr>
   </table>

در این مثال، دو سطر داریم که هرکدام شامل دو سلول هستند.
خروجی در مرورگر به صورت یک جدول ساده دیده می‌شود.

گاهی لازم است که عنوانی برای هر ستون یا سطر داشته باشیم.
برای نوشتن عنوان‌ها، از تگ ``<th>`` (مخفف Table Header) استفاده می‌کنیم.
تجهیزات یا عنوان‌های نوشته‌شده در ``<th>`` معمولاً به‌صورت **پررنگ** و **وسط‌چین** نمایش داده می‌شوند.

**مثال کامل‌تر:**

.. code-block:: html

   <table border="1">
       <tr>
           <th>نام</th>
           <th>رشته</th>
           <th>نمره</th>
       </tr>
       <tr>
           <td>علی</td>
           <td>طراحی وب</td>
           <td>۱۸</td>
       </tr>
       <tr>
           <td>نگار</td>
           <td>گرافیک</td>
           <td>۲۰</td>
       </tr>
   </table>

نتیجه‌ی این کد در مرورگر جدولی است که دارای سه ستون (نام، رشته و نمره) می‌باشد.
ویژگی ``border="1"`` فقط برای ایجاد خط دور جدول استفاده شده تا بهتر دیده شود.

**خروجی جدول در مرورگر به شکلی مشابه جدول زیر خواهد بود:**

+------+------------+--------+
| نام  | رشته       | نمره   |
+======+============+========+
| علی  | طراحی وب   | ۱۸     |
+------+------------+--------+
| نگار | گرافیک     | ۲۰     |
+------+------------+--------+

**نکات مهم:**
- برای طراحی حرفه‌ای‌تر جدول‌ها بهتر است از CSS استفاده کنیم.
- می‌توانیم ویژگی‌هایی مانند رنگ، اندازه فونت یا فاصله بین خانه‌ها را با CSS تغییر دهیم.
- جدول‌ها زمانی استفاده می‌شوند که نیاز به چیدمان داده‌ها به‌صورت منظم و ردیفی داریم، نه برای طراحی کامل صفحه.

ادغام سلول‌ها: Colspan و Rowspan
------------------------------------

در جداول پیشرفته‌تر، گاهی یک سلول نیاز دارد که فضای چند سطر یا چند ستون را اشغال کند.
برای این کار دو ویژگی مهم به نام‌های ``colspan`` و ``rowspan`` وجود دارد.
این دو ویژگی مشابه ویژگی Merge Cells در نرم‌افزار ورد است.

۱. ادغام در طول ستون‌ها (Colspan)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

ویژگی ``colspan`` (مخفف Column Span) به یک سلول اجازه می‌دهد که به اندازه‌ی چند **ستون** جا اشغال کند
این ویژگی را به تگ ``<td>`` یا ``<th>`` اضافه می‌کنیم و تعداد ستون‌هایی که باید پوشانده شود را به آن می‌دهیم.

**مثال برای Colspan:**

اگر بخواهیم یک عنوان کلی برای دو ستون داشته باشیم:

.. code-block:: html

   <table border="1">
       <tr>
           <th colspan="2">اطلاعات تماس</th>
       </tr>
       <tr>
           <th>تلفن</th>
           <th>ایمیل</th>
       </tr>
       <tr>
           <td>021-33224466</td>
           <td>test@site.com</td>
       </tr>
   </table>

در این حالت، سلول اول (اطلاعات تماس) به اندازه‌ی دو ستون جا اشغال می‌کند.

+-------------+--------------+
|اطلاعات تماس                |
+-------------+--------------+
|تلفن         |ایمیل         |
+=============+==============+
|021-33224466 |test@site.com |
+-------------+--------------+

۲. ادغام در طول سطرها (Rowspan)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

ویژگی ``rowspan`` (مخفف Row Span) به یک سلول اجازه می‌دهد که **ارتفاع** چند سطر را بپوشاند.
این ویژگی نیز به تگ ``<td>`` یا ``<th>`` اضافه می‌شود و تعداد سطرهایی که باید پوشانده شود را مشخص می‌کند.

**مثال برای Rowspan:**

اگر نام یک شخص در دو سطر اطلاعاتی ثابت باشد:

.. code-block:: html

   <table border="1">
        <th>نمرات دانش‌آموزان</th>
       <tr>
           <td rowspan="2">محسن</td>
           <td>زبان</td>
           <td>۱۹</td>
       </tr>
       <tr>
           <td>ریاضی</td>
           <td>۱۷</td>
       </tr>
   </table>

خروجی:

+-------+--------+------+
|نمرات دانش آموزان      |
+=======+========+======+
|محسن   |زبان    |۱۹    |
|       +--------+------+
|       |ریاضی   |۱۷    |
+-------+--------+------+


در اینجا، سلول "محسن" به اندازه‌ی دو سطر جا اشغال می‌کند. به همین دلیل، در سطر دوم، دیگر نیازی به تعریف سلول اول نیست.

.. admonition:: نکته‌ی بسیار مهم
    :class: attention

    هنگامی که از ``colspan`` یا ``rowspan`` استفاده می‌کنید، باید تعداد سلول‌های ``<td>`` یا ``<th>`` در آن سطر (یا سطرهای تحت تأثیر ``rowspan``) را **کم** کنید تا تعداد کل ستون‌ها در هر سطر جدول، یکسان باقی بماند و جدول به هم نریزد.
