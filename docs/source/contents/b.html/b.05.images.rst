عنصر img یا تصویر
=====================

این عنصر برای درج تصویر به کار می‌رود. ویژگی ضروری این عنصر آدرس تصویر یا src است. برچسب img تک برچسبه است و برچسب پایان ندارد. مثال:

.. code-block:: html

    <img src="image.jpg">

.. admonition:: مثال

    .. image:: /images/sample-img.jpg
    

چند ویژگی عنصر تصویر
---------------------

width یا عرض
^^^^^^^^^^^^^^^^^

به کمک این ویژگی می‌توان عرض عکس را تعیین کرد. مثال:

.. code-block:: html

    width="200px"

height یا ارتفاع
^^^^^^^^^^^^^^^^^^^^^^

به کمک این ویژگی می‌توان ارتفاع عکس را تنظیم کرد.

.. note::

    نکته: سعی کنید از هر دو ویژگی width و height به طور همزمان استفاده نکنید تا نسبت ابعاد تصویر به هم نخورد.

ویژگی alt
^^^^^^^^^^^^^^^^^

اگر تصویر مشخص شده در تگ img
به هر دلیلی بارگذاری نشود،
در این صورت متن نوشته شده در این ویژگی نمایش داده می‌شود.
همچنین نرم‌افزارهای صفحه‌خوان که متن صفحه را برای افراد نابینا به صورت صوتی می‌خوانند،
از این ویژگی برای توصیف تصویر استفاده می‌کنند.
