صفحات قابل چاپ
======================================

یکی دیگر از معیارهای یک سایت خوب این است که علاوه بر مرورگرها،
در هنگام چاپ نیز مطالب به درستی نمایش داده شود.

از آنجایی که قالب صفحه در مرورگر و کاغذ بسیار متفاوت است و
اندازه نوشته‌ها و رنگ و سایر مختصات متن در هر کدام باید به گونه خاصی باشد،
و همچنین برخی عناصر تزئینی در خروجی چاپی نباید حضور داشته باشند،
به همین دلیل گاهی اوقات نیاز است برای حالت چاپ،
یک قالب
CSS
جداگانه طراحی کنیم.

برای این کار یک فایل
CSS
جدید ایجاد می‌کنیم.
(معمولا با نام print.css)
و بدین شکل به صفحه اضافه می‌کنیم.

.. code-block:: html

    <link src="./print.css" rel="stylesheet" media="print">

این کار کاملا مشابه افزودن یک فایل
CSS
قالب‌بندی مرورگر به صفحه است با این تفاوت که در انتهای آن عبارت
media="print"
را نیز درج می‌کنیم.

.. admonition:: نکته مهم
    :class: tip

    در فایل قالب بندی چاپ،
    به جای واحدهای اندازه گیری
    px و em و rem
    معمولا از واحدهای چاپی مانند
    cm و mm
    استفاده می‌شود.
