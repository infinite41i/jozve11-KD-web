روتوش تصاویر
=============

روتوش تصاویر به مجموعه اقداماتی گفته می‌شود که با هدف بهبود ظاهر عکس، حذف ایرادها و طبیعی‌تر شدن تصویر انجام می‌گیرد. در روتوش، هدف این نیست که تصویر غیرواقعی یا مصنوعی شود، بلکه تلاش می‌کنیم عکس نهایی تمیزتر، حرفه‌ای‌تر و چشم‌نوازتر به نظر برسد؛ طوری که بیننده متوجه دست‌کاری شدن آن نشود.

روتوش معمولاً بعد از اصلاحات پایه‌ای مثل تنظیم نور و رنگ انجام می‌شود و بیشتر روی جزئیات تصویر تمرکز دارد؛ مانند حذف لکه‌ها، جوش‌ها، گرد و غبار، خطوط اضافی یا ترمیم بخش‌های آسیب‌دیده عکس.

ابزارهای اصلی روتوش تصاویر
----------------------------

برای روتوش تصاویر، نرم‌افزارهایی مثل Photoshop ابزارهای متنوعی در اختیار ما قرار می‌دهند. هر ابزار کاربرد مشخصی دارد و انتخاب درست آن، نتیجه نهایی را بسیار طبیعی‌تر می‌کند.

Spot Healing Tool
##################

.. figure:: /images/photoshop/spot-healing-brush.jpg

   ابزار spot healing brush tool در فتوشاپ

ابزار **Spot Healing Tool** یکی از ساده‌ترین و سریع‌ترین ابزارهای روتوش است.
این ابزار برای حذف ایرادهای کوچک مثل جوش، لکه‌های ریز،
گرد و غبار یا نقطه‌های ناخواسته بسیار مناسب است.

نحوه کار این ابزار به این صورت است که شما فقط روی بخش مشکل‌دار کلیک می‌کنید
و نرم‌افزار به‌صورت هوشمند، بافت اطراف آن ناحیه را تحلیل کرده و جایگزین می‌کند.
به همین دلیل، برای اصلاح‌های سریع و جزئی انتخاب بسیار خوبی است.

.. figure:: /images/photoshop/spot-healing-example.jpg

   حذف جوش و لک پوستی به کمک ابزار Spot Healing Brush Tool

.. admonition:: نکته
    :class: tip

    این ابزار زمانی بهترین نتیجه را می‌دهد که:

    - ایراد تصویر کوچک باشد
    - اطراف آن بافت نسبتاً یکنواختی داشته باشد

Clone Stamp Tool
#################

.. figure:: /images/photoshop/clone-stamp-tool.jpg

   ابزار Clone Stamp Tool

ابزار **Clone Stamp Tool** یا همان Stamp Tool، یکی از دقیق‌ترین ابزارهای روتوش محسوب می‌شود. برخلاف Spot Healing که به‌صورت خودکار تصمیم می‌گیرد، در این ابزار کنترل کامل در اختیار کاربر است.

در استفاده از این ابزار، ابتدا با نگه داشتن کلید :kbd:`Alt` و کلیک روی یک ناحیه سالم، از آن قسمت نمونه‌برداری می‌کنید. سپس می‌توانید همان بخش را روی ناحیه موردنظر کپی کنید.

.. admonition:: نکته
    :class: tip
        
    Clone Stamp Tool برای مواقعی مناسب است که:

    - جزئیات تصویر حساس هستند
    - می‌خواهید بافت یا الگوی خاصی را دقیقاً حفظ کنید
    - ابزارهای خودکار نتیجه مطلوبی نمی‌دهند

.. admonition:: بیشتر بدانید
    :class: warning

    **Healing Brush Tool**

    **Healing Brush Tool** ترکیبی از دقت Clone Stamp و هوشمندی Spot Healing است. در این ابزار، شما ناحیه نمونه را به‌صورت دستی انتخاب می‌کنید، اما نرم‌افزار هنگام اعمال آن، نور و رنگ محیط مقصد را به‌طور خودکار با هم تطبیق می‌دهد.

    این ابزار برای روتوش پوست، حذف چین‌وچروک‌های ملایم و اصلاح بخش‌هایی که تفاوت رنگ دارند، بسیار کاربردی است و نتیجه‌ای طبیعی‌تر نسبت به Clone Stamp ایجاد می‌کند.

    **Patch Tool**

    ابزار **Patch Tool** بیشتر برای اصلاح نواحی بزرگ‌تر استفاده می‌شود. با این ابزار می‌توانید یک قسمت از تصویر را انتخاب کرده و آن را به ناحیه سالم دیگری بکشید تا جایگزین شود.

    Patch Tool برای حذف سایه‌های ناخواسته، چین‌های بزرگ یا لکه‌های وسیع کاربرد دارد و معمولاً در روتوش حرفه‌ای پرتره استفاده می‌شود.

نکته مهم در روتوش
------------------

در روتوش تصاویر، زیاده‌روی بزرگ‌ترین اشتباه است.
اگر بیش از حد از ابزارها استفاده شود،
تصویر حالت مصنوعی پیدا می‌کند و حس طبیعی خود را از دست می‌دهد.
همیشه بهتر است:

- با بزرگ‌نمایی مناسب کار کنید
- تغییرات را مرحله‌به‌مرحله انجام دهید
- هر چند وقت یک‌بار نتیجه را با تصویر اصلی مقایسه کنید

روتوش خوب، روتوشی است که دیده نشود، اما تأثیر خود را بگذارد.
