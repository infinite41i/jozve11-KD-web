قالب دهی صفحات وب با CSS
==============================

CSS: لباسی که به وب‌سایت می‌پوشانیم
----------------------------------------

اگر HTML
را اسکلت و محتوای یک وب‌سایت در نظر بگیریم، CSS
دقیقاً مثل لباس، رنگ، مدل مو، و آرایشی است که به آن اسکلت می‌پوشانیم تا زیبا، مرتب و کاربرپسند به نظر برسد.
بدون CSS،
همه وب‌سایت‌ها فقط متن‌های سیاه و سفید روی پس‌زمینه سفید خواهند بود.

در ادامه این فصل، با اصول پایه CSS آشنا می‌شویم و یاد می‌گیریم چگونه با استفاده از آن صفحات وب زیبا و جذاب بسازیم.
