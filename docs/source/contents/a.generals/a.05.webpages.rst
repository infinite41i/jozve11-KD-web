صفحات وب و وب‌سایت‌ها
============================

هر وب‌سایت از مجموعه‌ای از صفحات وب تشکیل شده است
که توسط لینک‌ها به یکدیگر مرتبط شده‌اند.
این صفحات
که با زبان های 
html،
CSS،
و JavaScript
نوشته می‌شوند،
در بستر وب (www)
و با پروتکل های HTTP یا HTTPS
منتقل شده و به کاربر نمایش داده می‌شوند.

مرورگرها
-----------

صفحات وب توسط نرم‌افزارهایی به نام مرورگر از زبان HTML
ترجمه شده و تبدیل به صفحات گرافیکی‌ای می‌شوند که برای کاربران قابل فهم و مطالعه باشد.
از مرورگرهای معروف می‌توان به
**Chrome**،
**Firefox**،
**Safari** و
**Edge**
اشاره کرد.

راه‌های دسترسی به صفحات وب
----------------------------------

دو راه عمده برای دسترسی به صفحات وب وجود دارد:

- **آدرس‌های URL**: هر صفحه وب دارای یک آدرس یکتا به نام URL
  (Uniform Resource Locator)
  است که با وارد کردن آن در نوار آدرس مرورگر می‌توان به صفحه مورد نظر دسترسی پیدا کرد.

- **موتورهای جستجو**: موتورهای جستجو مانند
  **Google**،
  **Bing**،
  و
  **DuckDuckGo**
  به کاربران کمک می‌کنند تا با وارد کردن کلمات کلیدی مرتبط، صفحات وب مورد نظر خود را پیدا کنند.

.. tip::

  معمولا موتورهای جستجو الگوریتم‌های پیچیده‌ای برای رتبه‌بندی صفحات وب بر اساس ارتباط و کیفیت آن‌ها دارند.
  وب‌سایت‌ها معمولا تلاش زیادی می‌کنند تا رتبه بهتری در موتورهای جستجو بگیرند؛ 
  چرا که بخش عمده مخاطبان سایت‌ها از طریق موتورهای جستجو جذب می‌شود.
  به این کار **بهینه سازی موتور جستجو** یا **Search Engine Optimization (SEO)**
  گفته می‌شود.
